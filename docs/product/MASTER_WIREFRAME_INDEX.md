## 7. 대표 정상 흐름

### 선수 등록

```text
팀·시즌·스쿼드 설정 → 선수 등록 → 중복 검토
→ 선수단 → 선수 상세 → 정보·소속 변경 → 변경 이력
```

### 훈련

```text
일정 캘린더 → 훈련 등록 → 예상 대상 → 훈련 계획
→ 준비 점검 → 실제 참가·블록 실행 → 기록 정리 → 완료
```

### 경기

```text
경기 등록 → 중복 확인 → 엔트리 → 라인업
→ 이벤트·실제 출전 → 결과 대조 → 완료 → 피드백·정정
```

### 선수 기록 확인

```text
선수단 → 선수 요약 → 통합 타임라인 또는 영역 탭
→ 기록 상세 → 원본 업무 → 수정·정정 → 선수 상세 반영
```

## 8. 공통 예외·복구 기준

| 상태 | 처리 |
| --- | --- |
| 필수값·기록 모순 | 해결 전 저장·완료 차단 |
| 실제 운영 가능한 예외 | 영향과 사유 확인 후 진행 |
| 아직 미완성 | 작성 중으로 저장하고 공개·집계 제외 |
| 통신 실패 | 입력 유지 후 동일 요청으로 재시도 |
| 동시 수정 | 서버값과 작성값을 비교한 뒤 다시 적용 |
| 완료 기록 변경 | 사유·권한·이전 값을 남기는 정정 |
| 게시된 일정 종료 | 삭제 대신 취소·연기·중단 사용 |
| 권한 없는 민감 기록 | 내용과 존재 여부를 노출하지 않음 |
