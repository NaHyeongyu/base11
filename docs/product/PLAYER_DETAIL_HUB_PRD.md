## 1. 목적

선수 상세를 기본 프로필 화면이 아니라 `선수 한 명과 관련된 모든 기록을 찾고 판단하고 원본 업무로 이동하는 운영 허브`로 정의합니다.

지도자는 선수 상세에서 다음 질문에 바로 답할 수 있어야 합니다.

1. 이 선수는 오늘 훈련과 경기에 참여할 수 있는가?
2. 최근 어떤 훈련과 경기에 실제로 참가했고 어느 정도 뛰었는가?
3. 성장·피지컬 수치는 어떻게 변하고 있는가?
4. 부상, 통증, 제한과 복귀 과정은 무엇인가?
5. 최근 상담, 코치 메모, 피드백과 다음 목표는 무엇인가?
6. 어느 시즌과 스쿼드에서 어떤 기록이 만들어졌는가?
7. 누가 언제 기록을 만들거나 정정했는가?

## 2. 핵심 원칙

1. 모든 기록은 동일한 `선수 원본 ID`를 기준으로 연결합니다.
2. 선수 상세는 원본 기록을 복사해 보관하지 않고 각 업무 기록을 조회해 보여줍니다.
3. 훈련·경기 참가 기록은 원본 세션에서 정정하고, 측정·상담·피드백·메모는 선수 상세에서 등록·정정합니다.
4. 선수 상세에서 원본으로 이동할 수 있는 `기록 보기`를 항상 제공합니다.
5. 현재 소속과 기록 발생 당시 소속을 구분해 표시합니다.
6. 기본 범위는 현재 시즌이며 `전체 기간`에서 이전 시즌 기록까지 이어서 볼 수 있습니다.
7. 등록 종료·졸업 후에도 과거 기록은 읽기 전용으로 유지합니다.
8. 의료 상세, 상담 메모와 코치 내부 기록은 같은 화면 안에서도 권한별로 분리합니다.
9. 완료된 훈련·경기 기록은 선수 상세에서 직접 고치지 않고 정정 절차를 사용합니다.
10. 요약 수치마다 계산 근거가 된 기록으로 이동할 수 있어야 합니다.

## 3. 정보 범위

| 기록 영역 | 포함 내용 | 기준 원본 | 기본 접근 |
| --- | --- | --- | --- |
| 기본 정보 | 이름, 생년월일, 사진, 학교, 학년, 주발, 포지션 | 선수 프로필 | 감독·관리자, 제한된 코치 |
| 소속 | 시즌 등록, 스쿼드, 등번호, 운영 그룹, 등록 상태 | 시즌·스쿼드 등록 | 담당 지도자 |
| 참가 가능 | 정상·제한·불가, 제한 내용, 종료 시각 | 메디컬·운영 판단 | 담당 지도자, 메디컬 |

| 경기 | 엔트리, 선발·교체, 실제 출전, 출전 시간, 이벤트, GPS | 경기·출전·이벤트 기록 | 담당 지도자 |
| 성장 | 신장, 체중, 측정일, 성장 추세 | 신체 측정 | 지도자, 피지컬 |
| 피지컬 | 스프린트, 점프, 지구력, 민첩성, 측정 조건 | 피지컬 테스트 | 지도자, 피지컬 |
| 컨디션·부상 | 컨디션, 통증, 부상, 재활, 복귀 단계 | 컨디션·메디컬 기록 | 역할별 제한 |
| 상담 | 상담 일시, 유형, 참석자, 요약, 후속 조치, 다음 확인일 | 상담 기록 | 작성자·승인된 역할 |
| 피드백·목표 | 코치 피드백, 개인 목표, 근거 기록, 검토일, 상태 | 피드백·목표 기록 | 담당 지도자 |
| 문서·동의 | 동의 상태, 인계 확인본, 만료일 | 동의·인계 기록 | 관리자·팀 매니저 |
| 변경 기록 | 정보 변경 전후, 정정 사유, 실행자, 시각 | 변경 이력 | 권한 있는 운영자 |

`모든 기록`은 모든 사용자에게 모든 원문을 공개한다는 뜻이 아닙니다. 기록의 존재와 내용은 역할·담당 범위·민감도에 따라 다르게 표시합니다.

## 4. 화면 정보 구조

### 4.1 상단 고정 영역

- 이름, 사진, 등번호, 주 포지션
- 현재 시즌과 주 소속 스쿼드
- 학년과 학교
- 팀 등록 상태
- 오늘 참가 가능 상태와 제한 요약
- 최근 정보 갱신 시각
- `기록 추가` 주 행동
- `정보 수정`, `등록 상태 변경`, `인계` 보조 메뉴

상단은 탭을 이동해도 유지합니다. `기록 추가`를 누르면 현재 사용자가 만들 수 있는 기록만 표시합니다.

### 4.2 탭

| 탭 | 목적 | 주요 내용 |
| --- | --- | --- |
| 요약 | 오늘 필요한 판단 | 확인 필요, 최근 활동, 성장 변화, 최근 상담·목표 |
| 훈련·경기 | 실제 활동 검토 | 훈련 참가, 경기 출전, GPS·RPE, 이벤트 |
| 성장·피지컬 | 장기 변화 확인 | 신체 측정, 테스트 결과, 추세와 측정 조건 |
| 컨디션·부상 | 참가 제한 판단 | 컨디션, 통증, 부상, 재활과 복귀 이력 |
| 상담·피드백 | 지도와 후속 조치 | 상담, 코치 메모, 피드백, 개인 목표 |
| 소속·정보 | 행정과 이력 | 기본 정보, 시즌·스쿼드·등번호, 계정, 변경 기록 |

탭은 기록을 분리해 저장하는 기준이 아니라 같은 선수 기록을 찾기 위한 보기입니다.

## 5. 요약 화면

### 5.1 우선순위

1. 오늘 확인할 문제
2. 현재 참가 판단
3. 최근 훈련·경기 실제 참가
4. 최근 성장·피지컬 변화
5. 최근 상담·피드백과 후속 조치
6. 기본 정보와 소속

요약에는 모든 원문을 펼치지 않습니다. 각 카드에는 최근 핵심값, 확인 상태, 기록일과 해당 탭으로 이동하는 행동을 제공합니다.

## 6. 통합 기록 타임라인

훈련, 경기, 측정, 부상, 상담과 소속 변경을 요약 화면의 한 시간축에서 확인합니다. 별도 탭을 만들지 않아 탐색 단계를 줄이며, 기록이 많아지면 `전체 보기` 패널에서 기간·유형 필터를 사용합니다.

### 6.1 필터

- 기간: 현재 시즌 / 이전 시즌 / 전체 기간 / 직접 선택
- 기록 유형: 훈련 / 경기 / 성장 / 피지컬 / 컨디션 / 부상 / 상담 / 피드백 / 목표 / 소속 / 정정
- 스쿼드: 기록 당시 소속 기준
- 작성자·담당자
- 상태: 정상 / 확인 필요 / 정정됨 / 취소됨

### 6.2 기록 카드

- 기록 일시와 유형
- 한 줄 요약
- 기록 당시 팀·시즌·스쿼드
- 작성자 또는 원본 업무
- 공개 범위
- 정정·취소 상태
- `원본 기록 보기`

날짜가 같은 여러 기록은 합치지 않습니다. 같은 날의 훈련 참가와 상담은 날짜 묶음 안에서 별도 기록으로 표시합니다.

## 7. 훈련·경기 탭

### 7.1 상단 요약

- 선택 기간 훈련 참가 수와 실제 참가 시간
- 선택 기간 경기 엔트리·출전 수와 실제 출전 시간
- GPS 기록 보유율
- 평균 RPE와 총 세션 부하
- 득점·도움·카드

합계에는 `실제 참가·실제 출전`만 포함합니다. 계획 대상, 엔트리 포함과 벤치 대기는 별도 수치로 표시합니다.

### 7.2 기록 목록

| 공통 | 훈련 추가 | 경기 추가 |
| --- | --- | --- |
| 일시, 당시 스쿼드, 상태 | 목적, 실제 참가, 시간, 블록, GPS, RPE | 대회, 상대, 엔트리, 선발·교체, 출전 시간, 이벤트 |

- 완료되지 않은 세션은 `집계 전`으로 표시합니다.
- 취소된 일정은 참가 통계에서 제외하고 이력에는 남깁니다.
- 교차 스쿼드 참가는 당시 참가 방식과 원 소속을 함께 표시합니다.
- 목록 선택 시 기록 상세 패널을 열고 원본 세션·경기로 이동할 수 있습니다.

## 8. 성장·피지컬 탭

- 지표 선택: 신장, 체중, 스프린트, 점프, 지구력, 민첩성 등
- 기간과 연령 기준
- 측정값, 측정일, 측정 조건, 측정자
- 같은 조건의 기록만 연결한 추세
- 최근 값과 이전 값의 차이
- 측정 누락·오래된 측정 표시

단위나 측정 방식이 다른 값은 한 추세선으로 합치지 않습니다. 측정값 정정은 이전 값을 남기고 새 버전을 생성합니다.

## 9. 컨디션·부상 탭

- 오늘 컨디션과 통증
- 현재 참가 제한과 적용 기간
- 부상 발생, 진단 확인 상태, 재활 단계와 복귀 기록
- 훈련·경기에서 발생한 부상 이벤트 연결
- 다음 확인일과 담당자

지도자는 참가에 필요한 제한 요약을 볼 수 있지만 진단 원문은 메디컬 권한이 있는 사용자만 볼 수 있습니다.

## 10. 상담·피드백 탭

### 10.1 상담 기록

- 상담 일시와 유형: 정기 / 경기 후 / 진로 / 생활 / 보호자 / 기타
- 참석자
- 상담 요약
- 지도자 내부 메모
- 합의한 후속 조치
- 담당자와 다음 확인일
- 공개 범위

### 10.2 피드백·목표

- 피드백 내용과 근거가 된 훈련·경기
- 선수 개인 목표
- 기준값, 목표값과 검토 주기
- 진행 상태와 종료 사유

상담 원문은 기본적으로 팀 내부 제한 기록입니다. 진학·이적 인계에는 자동 포함하지 않으며 별도 동의와 명시적 선택이 있어도 상담 요약본만 제공합니다.

## 11. 소속·정보 탭

- 기본 정보
- 현재 시즌 등록과 참가 가능 스쿼드
- 운영 그룹
- 시즌별 공식 스쿼드·등번호·포지션 이력
- 등록 일시 중지·종료·졸업 기록
- 교차 스쿼드 참가 이력
- 선수 계정 연결 상태
- 동의와 인계 상태
- 주요 변경 기록

현재 정보와 과거 값을 같은 입력 양식에 섞지 않습니다. 과거 이력은 읽기 전용이며 잘못된 값은 정정 절차로 처리합니다.

## 12. 주요 업무 흐름

### 12.1 기록 확인

```text
선수단 → 선수 선택 → 요약 → 확인할 항목 선택
→ 관련 탭의 필터 적용 → 기록 상세 패널 → 원본 기록 보기
```

### 12.2 기록 추가

```text
선수 상세 → 기록 추가 → 권한 있는 기록 유형 선택
→ 해당 등록 화면 열기 → 선수 자동 지정 → 저장
→ 선수 상세의 해당 탭과 요약 타임라인에 즉시 반영
```

훈련과 경기는 선수 한 명 기준으로 새 일정을 만들지 않습니다. 기존 훈련 참가자 또는 경기 엔트리·출전 기록에 연결합니다.

### 12.3 상담 등록

```text
상담·피드백 → 상담 기록 추가 → 유형·참석자·요약 입력
→ 공개 범위 확인 → 후속 조치·다음 확인일 지정 → 저장
→ 요약 타임라인과 확인할 내용에 반영
```

### 12.4 완료 기록 정정

```text
기록 상세 → 원본 기록 보기 → 정정 요청
→ 권한·사유 확인 → 이전 값 보존 → 정정 완료
→ 선수 상세에 정정 상태와 최신 값 반영
```

### 12.5 시즌 전환·졸업

```text
현재 시즌 종료 → 이전 시즌 기록 잠금
→ 새 시즌 등록 생성 또는 등록 종료
→ 선수 상세 기본 범위를 새 시즌으로 변경
→ 전체 기간에서 과거 기록 계속 조회
```

## 13. 예외 처리

| 상황 | 처리 | 화면 표시 |

| 권한 없는 민감 기록 | 필드 차단 | 내용과 존재를 노출하지 않음 |

| 계획 대상이지만 불참 | 구분 표시 | 참가 0분, 불참 사유가 있으면 표시 |
| 경기 엔트리지만 미출전 | 구분 표시 | 엔트리 포함·미출전, 출전 통계 제외 |
| 교차 스쿼드 참가 | 당시 기준 보존 | 원 소속과 참가 스쿼드 모두 표시 |

| 단위·측정 방식이 다름 | 추세 분리 | 비교 불가 사유와 별도 기록 표시 |
| 중복 선수 ID 의심 | 관리자 확인 | 자동 합치지 않고 병합 검토 상태 표시 |
| 저장 중 권한 변경 | 저장 차단 | 입력 유지, 권한 변경 안내 |
| 다른 사용자가 먼저 수정 | 비교 후 재시도 | 서버값과 작성값을 나란히 표시 |
| 이전 시즌 선수 | 읽기 전용 | 시즌 배지와 현재 시즌으로 돌아가기 제공 |
| 졸업·등록 종료 선수 | 보관 조회 | 새 기록 추가 제한, 과거 기록 유지 |
| 진학·이적 선수 | 기관별 분리 | 현재팀 기록과 출신팀 확인본을 구분 |
| 공유 동의 철회 | 접근 종료 | 공유값 미표시, 철회 이력만 관리자 확인 |
| 상담 후속 조치 지연 | 확인 필요 | 요약 상단과 상담 탭에 기한 초과 표시 |

## 15. UI/UX 규칙

1. 요약 화면에는 카드마다 하나의 판단과 하나의 이동 행동만 둡니다.
2. 모든 기록에 기록일, 작성자·원본, 당시 소속과 상태를 표시합니다.
3. 통합 기록 타임라인은 최신순이 기본이며 긴 타임라인은 월 단위로 나눕니다.
4. 필터 적용 결과와 전체 건수를 함께 보여줍니다.
5. 그래프만 제공하지 않고 정확한 측정값 표를 함께 제공합니다.
6. 상태는 색상과 문구를 함께 사용합니다.
7. 내부 메모, 공유 피드백, 상담 요약을 같은 문구 영역에 섞지 않습니다.
8. `AI 분석`, `스마트 인사이트` 같은 표현을 사용하지 않습니다.
9. `기록 없음`, `권한 없음`, `집계 전`, `정정됨`을 서로 다른 상태로 표시합니다.
10. 모바일에서는 상단 정보와 확인할 내용, 최근 기록을 우선하고 탭은 가로 스크롤로 제공합니다.

## 16. 완료 조건

### 기록 연결

- [ ] 한 선수의 현재·이전 시즌 기록을 전체 기간에서 볼 수 있다.
- [ ] 훈련 계획 대상과 실제 참가를 구분할 수 있다.
- [ ] 경기 엔트리, 라인업과 실제 출전을 구분할 수 있다.
- [ ] 성장·피지컬·부상·상담·피드백 기록을 같은 선수 ID로 찾을 수 있다.
- [ ] 모든 요약값에서 근거 원본으로 이동할 수 있다.

### 운영

- [ ] 오늘 확인할 제한과 후속 조치를 요약 첫 화면에서 발견할 수 있다.
- [ ] 기록 추가 메뉴는 사용자 권한에 맞는 항목만 제공한다.
- [ ] 완료 기록 정정이 선수 상세와 원본에 동일하게 반영된다.
- [ ] 졸업·등록 종료 후에도 과거 기록이 유지된다.
- [ ] 시즌과 기록 당시 스쿼드가 현재 소속으로 덮어써지지 않는다.

### 개인정보

- [ ] 의료 원문과 상담 메모가 권한 없는 사용자에게 노출되지 않는다.
- [ ] 진학·이적 시 상담·의료 기록이 자동 공유되지 않는다.
- [ ] 공유 철회 후 수신팀에서 해당 내용을 열 수 없다.
- [ ] 직접 URL 접근에서도 같은 권한 검사가 적용된다.
