## 1. 팀 최초 설정

```mermaid
flowchart TD
    A["구단·기관 선택"] --> B{"기존 팀이 있는가?"}
    B -- "예" --> C["팀 선택"]
    B -- "아니요" --> D["팀 이름·지역·시간대 입력"]
    D --> C
    C --> E{"운영 중 시즌이 있는가?"}
    E -- "예" --> F["현재 시즌 확인"]
    E -- "아니요" --> G["시즌 이름·기간 생성"]
    G --> H["공식 스쿼드 생성"]
    F --> I{"공식 스쿼드가 있는가?"}
    I -- "예" --> J["팀 매니저·스태프 배정"]
    I -- "아니요" --> H
    H --> J
    J --> K["선수 개별 등록 또는 파일 등록"]
    K --> L["중복·필수값·등번호 충돌 확인"]
    L --> M{"오류가 남았는가?"}
    M -- "예" --> K
    M -- "아니요" --> N["시즌 명단 활성화"]
```

### 완료 상태

- 운영 중 팀 1개
- 운영 중 시즌 1개
- 공식 스쿼드 1개 이상
- 팀 매니저 또는 감독 1명 이상
- 활동 중 선수 1명 이상

## 2. 선수 개별 등록

```mermaid
flowchart TD
    A["선수단에서 선수 등록 선택"] --> B["이름·생년월일 입력"]
    B --> C["같은 구단 안에서 중복 후보 확인"]
    C --> D{"중복 후보가 있는가?"}
    D -- "아니요" --> E["새 선수 기본 정보 입력"]
    D -- "예" --> F["후보의 생년월일·팀·지난 시즌 확인"]
    F --> G{"같은 선수인가?"}
    G -- "예" --> H["기존 선수에 새 팀 등록 연결"]
    G -- "아니요" --> E
    G -- "판단 어려움" --> I["관리자 확인 대기"]
    E --> J["등록 대기로 저장"]
    H --> J
    J --> K["시즌·공식 스쿼드·학년·주 포지션 입력"]
    K --> L{"필수값과 기간이 유효한가?"}
    L -- "아니요" --> K
    L -- "예" --> M{"등번호를 입력했는가?"}
    M -- "아니요" --> N["활동 중으로 전환"]
    M -- "예" --> O{"같은 스쿼드·기간에 번호가 겹치는가?"}
    O -- "예" --> K
    O -- "아니요" --> N
    N --> P["선수단 목록과 일정 대상에 표시"]
```

### 중단 후 재개

- 기본 정보 저장 후 나가면 `등록 대기`에 남습니다.
- 시즌 명단 입력을 완료할 때까지 일정 대상에는 포함하지 않습니다.
- 관리자 확인 대기 중인 중복 후보는 새 선수로 확정되지 않습니다.

## 3. 선수 파일 등록

```mermaid
flowchart TD
    A["파일로 등록 선택"] --> B["양식 내려받기 또는 기존 파일 선택"]
    B --> C["파일 열과 BASE11 항목 연결"]
    C --> D["필수값·날짜·시즌·스쿼드 검사"]
    D --> E["기존 선수·등번호 중복 검사"]
    E --> F["행을 등록 가능 / 확인 필요 / 등록 불가로 분류"]
    F --> G{"확인 필요 행이 있는가?"}
    G -- "예" --> H["기존 선수 연결·새 선수 등록·보류 선택"]
    H --> I["표 안에서 값 수정"]
    I --> D
    G -- "아니요" --> J{"등록 불가 행이 있는가?"}
    J -- "예" --> K["가능한 행만 등록 또는 전체 수정 선택"]
    J -- "아니요" --> L["등록 실행"]
    K --> L
    L --> M["완료·기존 연결·등록 대기·제외 수 확인"]
    M --> N["제외 행 파일 내려받기"]
```

### 파일 등록 원칙

- 파일 선택만으로 저장하지 않습니다.
- 모든 행은 검사 결과를 먼저 보여줍니다.
- 등록 가능한 행만 먼저 처리할 수 있습니다.
- 오류가 있는 원본 파일을 덮어쓰지 않습니다.

## 4. 공식 스쿼드·등번호·포지션 변경

```mermaid
flowchart TD
    A["선수 상세의 소속·이력 열기"] --> B["변경 종류 선택"]
    B --> C["새 값·적용일·사유 입력"]
    C --> D{"기존 기록 기간과 겹치는가?"}
    D -- "예" --> E["겹치는 기록과 기간 표시"]
    E --> C
    D -- "아니요" --> F{"등번호 변경인가?"}
    F -- "아니요" --> G["변경 전·후 확인"]
    F -- "예" --> H{"같은 스쿼드·기간에 번호가 겹치는가?"}
    H -- "예" --> I["겹치는 선수와 기간 표시"]
    I --> C
    H -- "아니요" --> G
    G --> J["기존 기록 종료일 설정"]
    J --> K["새 기록 생성"]
    K --> L["변경 이력 저장"]
```

### 결과

- 현재 값은 적용일 기준으로 바뀝니다.
- 적용일 전 세션은 이전 소속·번호·포지션을 유지합니다.
- 이미 끝난 시즌을 정정할 때는 구단 관리자 권한이 필요합니다.

## 5. 선수 등록 종료와 복구

```mermaid
flowchart TD
    A["선수 상세에서 등록 종료 선택"] --> B["종료일·종료 사유 입력"]
    B --> C["내부 메모 입력 선택"]
    C --> D["향후 일정과 운영 그룹 영향 확인"]
    D --> E{"종료일 이후 일정에 이미 포함되어 있는가?"}
    E -- "예" --> F["영향 일정 목록 표시"]
    F --> G["일정에서 제외 후 종료 또는 취소 선택"]
    G --> H["등록 종료 확인"]
    E -- "아니요" --> H
    H --> I["종료일 이후 새 일정 대상에서 제외"]
    I --> J["과거 세션·측정·메모 유지"]
    J --> K["변경 이력 저장"]
```

### 복구

```mermaid
flowchart TD
    A["종료 선수 목록에서 선수 선택"] --> B["등록 복구 선택"]
    B --> C["복구일·시즌·스쿼드 입력"]
    C --> D{"같은 기간의 등록이 있는가?"}
    D -- "예" --> E["기존 등록 확인 또는 새 팀 등록 취소"]
    D -- "아니요" --> F["활동 중 등록 생성"]
    F --> G["복구 사유와 실행자 기록"]
```

## 6. 다음 시즌 명단 구성

```mermaid
flowchart TD
    A["팀 관리에서 다음 시즌 만들기"] --> B["시즌 이름·기간 입력"]
    B --> C["공식 스쿼드 구성"]
    C --> D["이전 시즌 선수 불러오기"]
    D --> E["선수별 처리 상태 선택"]
    E --> F{"처리 상태"}
    F -- "다음 시즌 등록" --> G["스쿼드·학년·포지션·등번호 입력"]
    F -- "졸업" --> H["종료일·졸업 사유 입력"]
    F -- "이적·퇴단" --> I["종료일·종료 사유 입력"]
    F -- "결정 보류" --> J["보류 목록에 유지"]
    G --> K["필수값·등번호 충돌 검사"]
    H --> K
    I --> K
    J --> L{"보류 선수가 남았는가?"}
    K --> L
    L -- "예" --> E
    L -- "아니요" --> M["감독 또는 팀 매니저 최종 확인"]
    M --> N["시작일에 새 시즌 운영 중 전환"]
    N --> O["이전 시즌 종료"]
```

### 새 시즌에 이어지는 것

- 선수 원본
- 기본 축구 정보
- 같은 구단 안의 팀 등록 이력
- 허용된 연락 정보

### 새 시즌에서 다시 정하는 것

- 공식 스쿼드
- 학년
- 주 포지션 확인
- 등번호
- 학교
- 시즌 등록 상태

## 7. 중복 후보 처리와 병합

```mermaid
flowchart TD
    A["개별·파일 등록 중 중복 후보 발견"] --> B["이름·생년월일·과거 팀·계정 연결 비교"]
    B --> C{"같은 선수라고 확인되는가?"}
    C -- "예" --> D["기존 선수 연결"]
    C -- "아니요" --> E["새 선수 등록"]
    C -- "불확실" --> F["관리자 확인 대기"]
    F --> G["구단 관리자가 양쪽 기록 비교"]
    G --> H{"이미 별도 선수로 저장되었는가?"}
    H -- "아니요" --> D
    H -- "예" --> I["기준 선수 선택"]
    I --> J["시즌·세션·측정·계정 충돌 검사"]
    J --> K{"충돌이 있는가?"}
    K -- "예" --> L["충돌 해결 후 재검사"]
    L --> J
    K -- "아니요" --> M["기록을 기준 선수로 이동"]
    M --> N["병합 전·후 ID와 실행자 기록"]
```

중복 후보는 같은 구단 안에서만 찾습니다. 다른 구단의 선수는 검색하거나 연결하지 않습니다.

## 8. 스태프 초대와 권한

```mermaid
flowchart TD
    A["스태프·권한에서 초대 선택"] --> B["이름·연락 수단 입력"]
    B --> C["주 역할 선택"]
    C --> D["담당 스쿼드·영역 선택"]
    D --> E["권한 미리보기"]
    E --> F["초대 발송"]
    F --> G{"초대를 수락했는가?"}
    G -- "아니요" --> H["초대 대기 · 재발송 또는 취소"]
    G -- "예" --> I["활성 상태로 전환"]
    I --> J["권한 변경 이력 저장"]
```

팀 매니저는 초대와 비활성화를 처리할 수 있지만 구단 관리자 권한 부여와 중복 선수 병합 권한은 줄 수 없습니다.

## 9. 졸업·진학 데이터 인계

```mermaid
flowchart TD
    A["시즌 전환에서 졸업·이적 선택"] --> B["팀 등록 종료일·사유 입력"]
    B --> C["졸업생 또는 종료 선수로 전환"]
    C --> D{"새 학교에 기록 인계가 필요한가?"}
    D -- "아니요" --> E["과거 기록 읽기 전용 보관"]
    D -- "예" --> F["수신 학교·구단 정확히 선택"]
    F --> G["목적·제공 범위·이용 기간 선택"]
    G --> H{"만 14세 미만인가?"}
    H -- "예" --> I["법정대리인 동의와 확인"]
    H -- "아니요" --> J["선수 본인 동의"]
    I --> K["출신팀 확인본 생성"]
    J --> K
    K --> L["일회용 인계 코드·만료 링크 발급"]
    L --> M["수신팀 관리자 검토·수락"]
    M --> N["기존 선수 식별자와 수신팀 등록 대기 연결"]
    N --> O["출신팀 확인값과 수신팀 현재값 분리 표시"]
    O --> P["수신팀 새 시즌 등록 생성"]
```

다른 구단의 선수는 이름이나 생년월일로 검색하지 않습니다. 연결은 유효한 인계 건을 통해서만 가능하며 열람·반영·다운로드·철회를 모두 기록합니다.
