## 1. 와이어프레임 목적

색상과 브랜드 표현을 정하기 전에 화면의 정보 순서, 이동 경로, 버튼 수와 편집 단위를 확인합니다. 이 문서의 화면은 시각 디자인 시안이 아니라 기능 배치 기준입니다.

## 2. 공통 화면 틀

### 데스크톱

```text
┌──────────────┬───────────────────────────────────────────────┐
│ 팀 선택      │ 현재 팀 / 시즌 / 스쿼드          계정·알림   │
│              ├───────────────────────────────────────────────┤
│ 오늘         │ 화면 제목                         주 행동 1개 │
│ 일정         │ 화면 설명                                    │
│ 선수단       ├───────────────────────────────────────────────┤
│ 세션         │                                               │
│ 공지         │ 화면별 본문                                   │
│ 팀 관리      │                                               │
│              │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

- 좌측 메뉴에는 `선수단`과 `팀 관리`를 분리합니다.
- 상단에는 현재 팀과 시즌을 항상 표시합니다.
- 스쿼드는 화면 전체 범위가 바뀌는 곳에서만 선택합니다.
- 화면 제목 오른쪽의 강조 행동은 하나만 둡니다.
- 페이지 안에서 같은 명단을 두 번 보여주지 않습니다.

### 모바일

```text
┌────────────────────────┐
│ 팀 / 시즌        메뉴  │
├────────────────────────┤
│ 화면 제목              │
│ 화면 설명              │
├────────────────────────┤
│ 검색·필터              │
├────────────────────────┤
│ 한 열 목록             │
│                        │
├────────────────────────┤
│ 필요한 경우 주 행동    │
└────────────────────────┘
```

- 표는 선수별 카드 또는 두 줄 목록으로 바꿉니다.
- 일괄 등록, 시즌 전환, 권한 변경은 모바일에서 제공하지 않습니다.
- 모바일 주 행동은 하단 고정 영역을 사용할 수 있습니다.

## 3. PL-01 선수단 목록

### 데스크톱 구조

```text
┌──────────────────────────────────────────────────────────────┐
│ 선수단                                      [선수 등록 ▾]    │
│ 현재 시즌의 선수와 등록 상태를 관리합니다.                  │
├──────────────────────────────────────────────────────────────┤
│ [검색________________] [스쿼드] [상태] [포지션] [정보 누락] │
├──────────────────────────────────────────────────────────────┤
│ 현재 명단 26  │ 등록 대기 2 │ 종료 선수 5                    │
├────┬────────┬────┬────┬────────┬────────┬──────────┬─────────┤
│ □  │ 선수   │소속│번호│학년·P  │등록상태│참가 가능 │정보 누락│
├────┼────────┼────┼────┼────────┼────────┼──────────┼─────────┤
│ □  │김민수  │U18 │11  │3·FW    │활동 중 │전체 참가 │없음     │
│ □  │이도윤  │U17 │4   │2·DF    │활동 중 │제한 참가 │연락처   │
│ □  │박준호  │—   │—   │1·MF    │등록대기│—         │스쿼드   │
└────┴────────┴────┴────┴────────┴────────┴──────────┴─────────┘
```

### 행동

- `선수 등록` 메뉴: `한 명 등록`, `파일로 등록`
- 행 선택: 선수 상세 진입
- 체크박스 선택 후 일괄 작업 막대 표시
- 등록 대기 행은 목록 위쪽에 배치
- 종료 선수 탭에서는 등록 종료일과 사유를 표시

### 사용하지 않는 구성

- 등록 선수 수만 보여주는 큰 숫자 카드
- 선수마다 정상 상태 배지 반복
- 목표 진척률과 세션 부하를 기본 등록 표에 함께 표시
- 계정 연결률을 선수단의 핵심 지표로 표시

## 4. PL-02 선수 개별 등록

### 공통 단계 표시

```text
1 중복 확인 ─── 2 기본 정보 ─── 3 시즌 명단
```

단계는 팝업이 아니라 독립 페이지 안에서 진행합니다.

### 1단계: 중복 확인

```text
┌──────────────────────────────────────────────────────────────┐
│ 선수 등록                                                    │
│ 1 중복 확인 ─ 2 기본 정보 ─ 3 시즌 명단                      │
├──────────────────────────────────────────────────────────────┤
│ 이름 *       [________________________]                       │
│ 생년월일 *   [____-__-__]                                    │
│                                                              │
│ 기존 선수 후보                                               │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 김민수 · 2008.03.12 · 2025 U17 · 등록 종료              │ │
│ │                              [기존 선수 연결]            │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                      [새 선수로 계속]        │
└──────────────────────────────────────────────────────────────┘
```

후보가 없으면 `같은 구단에서 일치하는 선수를 찾지 못했습니다.`만 표시합니다.

### 2단계: 기본 정보

```text
┌──────────────────────────────────────────────────────────────┐
│ 이름 *       [김민수_________________]                        │
│ 생년월일 *   [2008-03-12]       영문 이름 [______________]   │
│ 입단일 *     [2026-01-02]       현재 시즌 [2026 시즌 ▾]     │
│                                                              │
│ [이전]                         [등록 대기로 저장] [다음]     │
└──────────────────────────────────────────────────────────────┘
```

### 3단계: 시즌 명단

```text
┌──────────────────────────────────────────────────────────────┐
│ 공식 스쿼드 * [U18 ▾]         학년 *      [3학년 ▾]         │
│ 주 포지션 *   [FW ▾]          세부 포지션 [ST, W ▾]         │
│ 등번호        [11]             주발         [오른발 ▾]       │
│                                                              │
│ 등록 후 일정과 세션 대상에서 이 선수를 선택할 수 있습니다.  │
│ [이전]                                      [명단에 등록]    │
└──────────────────────────────────────────────────────────────┘
```

등번호가 겹치면 필드 아래에 겹치는 선수와 기간을 표시합니다.

- 등록 버튼에는 실제 처리될 인원수를 표시합니다.

## 6. PL-05 선수 상세

선수 상세의 통합 기록, 기록 연결과 예외 상태는 [선수 상세 전체 기록 허브 기획서](./PLAYER_DETAIL_HUB_PRD.md)를 기준으로 합니다.

### 구조

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ‹ 선수단   김민수  11 · FW   U18   활동 중   제한 참여             │
│ 학교·3학년 · 최근 갱신 8월 22일             [기록 추가] [관리 ▾] │
├──────────────────────────────────────────────────────────────────────┤
│ 요약 │ 훈련·경기 │ 성장·피지컬 │ 컨디션·부상 │ 상담·피드백 │ 정보·소속 │
├───────────────────────────────────────────┬──────────────────────────┤
│ 확인할 내용 2건                           │ 오늘 참가 판단           │
│ 발목 통증 재확인 · 상담 후속 조치 기한    │ 최대 60분 · 고강도 제한  │
├───────────────────────────────────────────┼──────────────────────────┤
│ 최근 훈련·경기                            │ 현재 목표                 │
│ 8/22 훈련 72분 · GPS 있음 · RPE 6         │ 압박 전 첫 터치 방향      │
│ 8/19 경기 선발 68분 · 도움 1              │ 다음 검토 8/30            │
├───────────────────────────────────────────┼──────────────────────────┤
│ 성장·피지컬 변화                          │ 최근 상담·피드백          │
│ 신장 +4.2cm/12개월 · 30m 4.18초           │ 8/15 개인 상담            │
├───────────────────────────────────────────┴──────────────────────────┤
│ 최근 기록 타임라인  훈련 · 경기 · 측정 · 상담 · 정정              │
└──────────────────────────────────────────────────────────────────────┘
```

### 탭 구성

- 요약: 오늘 확인할 문제와 최근 핵심 기록
- 요약 통합 기록: 허용된 모든 기록의 시간순 타임라인
- 훈련·경기: 실제 참가·출전, GPS·RPE와 경기 이벤트
- 성장·피지컬: 신체 측정과 테스트 추세
- 컨디션·부상: 참가 제한, 통증, 재활과 복귀
- 상담·피드백: 상담, 내부 메모, 후속 조치와 목표
- 소속·정보: 기본 정보, 시즌·스쿼드·등번호·변경 이력

### `정보 수정` 메뉴

- 기본 정보 수정
- 소속·등번호 변경
- 운영 그룹 변경
- 등록 일시 중지
- 등록 종료

`선수 삭제`는 표시하지 않습니다. 삭제 가능한 등록 대기 선수에게만 별도 관리 메뉴에서 `등록 대기 정보 삭제`를 제공합니다.

- 잘못 연결한 경우 변경 기록을 남기고 연결을 해제할 수 있어야 합니다.

## 14. 화면 상태

추가 화면은 `졸업생 관리`, `진학·이적 인계`, `인계 수신 검토`로 구분합니다. 수신팀 화면에서는 `출신팀 확인 정보`와 `현재 학교 정보`를 별도 영역으로 표시하고, 제공되지 않은 정보는 존재 여부도 노출하지 않습니다.

모든 주요 화면에 다음 상태를 설계합니다.

| 상태 | 표시 기준 |
| --- | --- |
| 불러오는 중 | 이전 내용이 있으면 유지하고 작은 진행 상태 표시 |
| 빈 상태 | 다음 작업 한 가지와 이유 표시 |
| 검색 결과 없음 | 적용된 검색·필터와 초기화 제공 |
| 저장 중 | 편집 영역 가까이 표시 |
| 저장 실패 | 실패한 항목과 다시 시도 제공 |
| 동시 수정 | 상대 변경 내용과 다시 불러오기 제공 |
| 권한 없음 | 필요한 역할과 요청 경로 표시 |
| 읽기 전용 | 종료 시즌 또는 보관 팀이라는 이유 표시 |

모든 오류 영역은 `문제 + 영향 + 다음 행동` 순서로 씁니다. 저장 실패와 권한 변경 시 입력값을 유지하고, 재시도는 같은 선수나 시즌 등록을 다시 만들지 않아야 합니다.

공통 예외 상태는 Figma에서 다음 8개 패턴으로 관리합니다.

| ID | 패턴 | 적용 화면 |
| --- | --- | --- |
| EX-01 | 불러오는 중 | 목록, 상세, 변경 기록 |
| EX-02 | 빈 상태·검색 결과 없음 | 모든 목록 화면 |
| EX-03 | 입력 충돌·검증 오류 | 등록, 편집, 시즌 전환 |
| EX-04 | 일괄 처리 일부 실패 | 파일 등록, 일괄 변경 |
| EX-05 | 저장 실패·재시도 | 모든 편집 화면 |
| EX-06 | 동시 수정 | 선수, 시즌, 권한 편집 |
| EX-07 | 권한 없음·읽기 전용 | 종료 시즌, 보관 팀, 제한 역할 |
| EX-08 | 동의 만료·철회 | 진학·이적 인계 |

## 15. 검토 순서

1. 팀·시즌·스쿼드 용어가 실제 팀 운영과 맞는지 확인
2. 선수 개별 등록의 필수 항목 확인
3. 기존 명단 파일로 일괄 등록 검사 항목 확인
4. 시즌 중 승격·등번호 변경 사례 확인
5. 졸업·이적·퇴단 처리와 지난 기록 유지 확인
6. 팀 매니저와 감독의 권한 차이 확인
7. 모바일에서 꼭 필요한 조회·수정 범위 확인

와이어프레임 승인 후 컬러, 폰트, 모서리와 세부 컴포넌트를 적용합니다.
