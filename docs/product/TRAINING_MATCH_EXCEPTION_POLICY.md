# 훈련·경기 예외 처리 정책

> 상태: 기획 검토용 0.1
> 최종 수정: 2026-08-23
> 운영 기준: [훈련·경기 등록 및 운영 정책](./TRAINING_MATCH_OPERATIONS_POLICY.md)

## 1. 목적

훈련과 경기 등록·운영 중 발생하는 충돌을 일관된 방식으로 처리합니다. 예외 화면은 단순 오류 메시지가 아니라 지도자가 현재 입력을 잃지 않고 다음 행동을 선택할 수 있게 해야 합니다.

## 2. 처리 단계

| 단계 | 적용 기준 | 화면 처리 |
| --- | --- | --- |
| 차단 | 저장하면 신원, 일정, 출전, 결과 이력이 모순됨 | 해결 전 주 행동 비활성화 |
| 확인 후 진행 | 실제 운영에서 가능한 예외지만 영향 확인 필요 | 영향과 사유 확인 후 진행 |
| 작성 중 유지 | 필수 정보나 결정이 부족함 | 초안 저장, 공개·실행 대상에서 제외 |
| 자동 복구 | 통신, 동기화, 일시적 서버 문제 | 입력 유지, 같은 요청으로 재시도 |
| 관리자 정정 | 완료된 공식 기록 변경 | 권한과 사유를 확인하고 새 이력 생성 |

## 3. 공통 표시 규칙

모든 예외는 다음 순서로 씁니다.

```text
문제 → 영향을 받는 대상 → 지금 할 수 있는 행동
```

예시:

```text
U18 훈련과 시간이 겹칩니다.
선수 4명과 담당 코치 1명이 두 일정에 포함되어 있습니다.
[겹치는 대상 확인] [시간 변경] [사유를 남기고 계속]
```

- 사용자가 입력한 값은 유지합니다.
- 문제가 있는 필드와 요약 영역을 함께 표시합니다.
- 실패한 저장을 다시 시도해도 훈련·경기·이벤트를 중복 생성하지 않습니다.
- 화면 전체를 막는 팝업은 저장 차단과 파괴적 작업에만 사용합니다.

## 4. 훈련 등록 예외

| 상황 | 처리 | 기준 |
| --- | --- | --- |
| 훈련명·날짜·시간·장소 누락 | 작성 중 유지 | 기본 정보가 완성되기 전에는 예정으로 확정하지 않음 |
| 대상이 0명 | 확인 후 진행 | `대상 미정` 사유가 있으면 초안·예정 가능, 시작 전 확정 필요 |
| 같은 선수가 여러 대상 규칙에 포함 | 자동 복구 | 한 명으로 합치고 포함 근거를 표시 |
| 등록 종료 선수가 대상에 포함 | 차단 | 일정 날짜에 활동 중인 등록이 있어야 함 |
| 참가 제한 선수가 자동 포함 | 확인 후 진행 | 제한 결과와 유효기간을 보여주고 제외·제한 참여 선택 |
| 담당 코치 없음 | 작성 중 유지 | 예정 확정 전 담당자 필요 |
| 담당 코치 일정 겹침 | 확인 후 진행 | 대체 담당자 또는 사유 필요 |
| 장소 일정 겹침 | 확인 후 진행 | 같은 장소 사용이 불가능한 팀 정책이면 차단 가능 |
| 계획 시간과 블록 합계가 다름 | 확인 후 진행 | 차이를 표시하고 전체 시간 또는 블록 조정 선택 |
| 블록 담당자의 권한이 회수됨 | 작성 중 유지 | 새 담당자 지정 전 계획 미완료 표시 |
| 템플릿의 그룹·스태프가 삭제됨 | 자동 복구 | 유효한 내용만 적용하고 다시 지정할 항목 표시 |
| 같은 일정으로 보이는 훈련이 있음 | 확인 후 진행 | 시간·장소·대상 비교 후 기존 일정 이동 또는 별도 생성 |

## 5. 훈련 실행 예외

| 상황 | 처리 | 기준 |
| --- | --- | --- |
| 예상 대상과 실제 참가자가 다름 | 정상 흐름 | 실제 참가자에 추가·제외 사유 기록 |
| 미등록 선수를 현장에서 추가 | 차단 | 먼저 등록 대기 또는 임시 참가 자격을 만들어야 함 |
| 다른 스쿼드 선수가 합류 | 확인 후 진행 | 공식 소속은 유지하고 참가 방식 기록 |
| 선수 지각 | 확인 후 진행 | 실제 시작 시각 또는 참여 시간 기록 |
| 선수 조기 종료 | 확인 후 진행 | 종료 시각과 사유 기록 |
| 제한 참여 | 확인 후 진행 | 참가 여부가 아니라 참여 범위·시간을 기록 |
| 실제 실행 순서가 계획과 다름 | 정상 흐름 | 계획을 덮어쓰지 않고 실제 순서 저장 |
| 훈련 중 장소 변경 | 확인 후 진행 | 현장 변경 이력과 영향 대상을 기록 |
| 담당자 없이 블록 실행 | 확인 후 진행 | 실제 담당자를 사후 지정하거나 `공동 진행` 사유 기록 |
| 참가자가 한 명도 없음 | 확인 후 진행 | 우천·팀 사정 등 사유 후 취소 또는 무참가 완료 선택 |
| 종료 버튼을 중복 누름 | 자동 복구 | 같은 종료 요청으로 처리하고 기록 하나만 생성 |

## 6. 훈련 종료·데이터 예외

| 상황 | 처리 | 기준 |
| --- | --- | --- |
| 실제 참가자 미확정 | 차단 | 완료 전 참가자 또는 무참가 사유 필요 |
| 종료 시각 없음 | 차단 | 실제 시간 또는 총 시간 필요 |
| GPS 일부 누락 | 확인 후 진행 | 완료 가능, 누락 선수와 데이터 완성도 표시 |
| GPS 선수가 참가자와 불일치 | 확인 후 진행 | 선수 연결·제외·보류 처리 |
| RPE 일부 누락 | 확인 후 진행 | 완료 가능, 후속 요청 대상으로 표시 |
| 후속 조치 담당자 없음 | 차단 | 필수 조치가 있으면 담당자 필요 |
| 완료 후 참가자 정정 | 관리자 정정 | 이전 값과 새 값, 사유를 남김 |
| 완료 후 훈련 삭제 | 차단 | 취소·정정·보관만 허용 |

## 7. 경기 등록 예외

| 상황 | 처리 | 기준 |
| --- | --- | --- |
| 상대 미정 | 작성 중 또는 확인 후 예정 | 토너먼트 대진 전이면 허용, 확인 필요 표시 |
| 장소 미정 | 작성 중 또는 확인 후 예정 | 이동·집결 준비 상태는 미완료 |
| 동일 대회·상대·킥오프 경기 존재 | 차단 | 기존 경기 이동 또는 별도 경기 확인 필요 |
| 같은 시간에 다른 경기 존재 | 차단 또는 확인 | 대상 스쿼드와 선수가 겹치면 차단, 대상 분리면 확인 |
| 대회·라운드 정보 누락 | 확인 후 진행 | 친선·연습경기는 허용, 공식전은 팀 정책에 따라 필수 |
| 홈·원정·중립 미정 | 작성 중 유지 | 예정 확정 전 선택 필요 |
| 엔트리 규칙 없음 | 확인 후 진행 | 기본 규칙으로 준비하되 `규정 미확인` 표시 |
| 경기 날짜가 시즌 밖 | 차단 | 시즌 변경 또는 별도 시즌 등록 필요 |

| 완료 후 점수 변경 | 관리자 정정 | 감독·관리자 권한과 사유 필요 |

| 결과 확인 중 이벤트 변경 | 차단 후 비교 | 변경된 이벤트를 불러와 점수 다시 검사 |
| 마지막 승인자 권한 해제 | 차단 | 대체 승인자 지정 필요 |

## 13. 표준 문구

### 저장 차단

```text
라인업을 확정할 수 없습니다.
선발이 12명이고 엔트리 밖 선수가 1명 포함되어 있습니다.
[문제 선수 확인]
```

### 확인 후 진행

```text
참가 제한 선수가 포함되어 있습니다.
제한 범위와 담당자의 확인 내용을 검토한 뒤 참가 방식을 선택해 주세요.
[제한 내용 확인] [선수 제외] [제한 참여]
```

### 저장 실패

```text
저장되지 않았습니다.
입력한 내용은 이 화면에 유지했습니다.
[다시 시도]
```

### 동시 수정

```text
다른 스태프가 먼저 변경했습니다.
최신 내용과 현재 입력을 비교한 뒤 다시 저장해 주세요.
[변경 비교]
```

### 취소·연기

```text
경기 일정이 연기됩니다.
기존 킥오프와 확정 엔트리는 기록으로 유지하며 새 경기일에 자격을 다시 확인합니다.
[연기 처리]
```

## 14. 출시 차단 조건

- [ ] 게시된 일정에 직접 삭제 기능이 없다.
- [ ] 예상 대상, 실제 참가자, 경기 엔트리와 실제 출전이 분리되어 있다.
