## 1. 목적

훈련과 경기를 단순 캘린더 일정이 아니라 `계획 → 대상 준비 → 현장 실행 → 기록 정리 → 다음 계획 반영`으로 이어지는 지도자 업무 단위로 만듭니다.

## 2. 해결할 문제

1. 일정, 훈련 계획, 출결, GPS와 피드백이 서로 다른 화면과 기록으로 흩어집니다.
2. 일정에 초대한 선수와 실제 참가한 선수가 섞여 통계와 회고가 부정확해집니다.
3. 경기 대상 스쿼드, 엔트리, 라인업과 실제 출전이 구분되지 않습니다.
4. 일정 변경·취소·연기 후 누구에게 어떤 영향이 생기는지 알기 어렵습니다.
5. 완료된 기록을 일반 편집이나 삭제로 바꾸면 과거 이력이 훼손됩니다.
6. 경기장 통신이 불안정하면 현장 기록을 잃거나 같은 기록이 중복될 수 있습니다.

## 3. 제품 목표

- 지도자가 5분 안에 훈련 기본 일정과 대상을 등록할 수 있습니다.
- 기존 템플릿을 사용해 10분 안에 훈련 블록과 담당자를 준비할 수 있습니다.
- 훈련 시작 전 제한 선수와 대상 충돌을 한 화면에서 확인할 수 있습니다.
- 경기 등록 후 엔트리, 라인업, 결과가 같은 경기 ID로 이어집니다.
- 완료 전 누락과 모순을 보여주되 GPS·피드백 누락 때문에 현장 업무를 막지 않습니다.
- 게시 이후 변경은 영향 확인과 변경 이력으로 남습니다.

## 4. 현재 구현 상태

### 이미 있는 기반

- 월·주 일정 화면과 훈련·경기 생성 진입
- 훈련 기본 정보, 목적, 코칭 포인트와 블록 편집
- 훈련 템플릿 저장·불러오기
- 세션 상세의 개요, 선수, GPS, 메모·피드백 탭
- 경기 목록과 다음 경기 요약 화면
- 서버의 경기, 마이크로사이클, 훈련 세션, 훈련 블록 모델
- 세션 변경 버전 충돌 감지와 변경 기록
- 세션 공개본 생성 기반

### 현재 부족한 부분

- 대상 스쿼드·운영 그룹·개인 추가·제외 편집
- 예상 대상과 실제 참가자의 분리 저장
- 실제 참가 방식, 지각, 조기 종료와 제한 참여
- 훈련 시작·기록 정리·완료 상태
- 게시 후 변경 영향 확인과 취소 정책
- 경기 등록 버튼에서 실제 생성 흐름
- 경기 엔트리, 라인업, 출전, 이벤트와 결과 데이터
- 경기 연기·취소·중단과 완료 후 정정
- 오프라인 임시 저장과 중복 재시도 방지

현재 세션 상세의 `일정 삭제`는 연결된 훈련 데이터까지 제거하는 방식이므로 이 기획에서는 게시된 일정에 대해 `일정 취소`로 교체합니다.

## 5. 사용자

### 5.1 감독

- 주간 훈련과 경기 준비의 최종 상태를 확인합니다.
- 엔트리·라인업·경기 결과를 확정합니다.
- 완료 기록의 정정을 승인합니다.

### 5.2 코치

- 담당 훈련을 계획하고 실제 참가와 훈련 내용을 기록합니다.
- 경기 엔트리·라인업을 제안하고 현장 이벤트를 기록합니다.
- 선수별 메모와 후속 조치를 남깁니다.

### 5.3 팀 매니저

- 일정, 장소, 상대, 대회와 집결 정보를 관리합니다.
- 일정 변경·연기·취소와 영향 대상을 확인합니다.
- 경기 엔트리 행정 상태를 관리합니다.

### 5.4 피지컬·메디컬 스태프

- 배정된 세션의 GPS·RPE와 참가 제한 결과를 관리합니다.
- 허용된 정보만 확인하며 지도자 내부 메모 전체를 기본 열람하지 않습니다.

## 6. 정보 구조

### 6.1 주 메뉴

| 메뉴 | 역할 |
| --- | --- |
| 일정 | 월·주 일정에서 훈련·경기를 만들고 상세로 이동 |

### 6.2 공통 범위

- 현재 팀
- 현재 시즌

- 일정 상태와 시작까지 남은 시간

## 8. 공통 UI/UX 규칙

1. 계획·준비 화면은 데스크톱 독립 페이지로 제공합니다. 긴 등록 흐름을 작은 모달 안에 넣지 않습니다.
2. 일정 캘린더에서는 빠른 기본 등록과 상세 등록 진입을 구분합니다.
3. 상세 화면 상단에는 `상태`, `시작 시각`, `대상·참가 인원`, `준비도`와 주 행동 하나만 표시합니다.
4. 상세 탭은 기록이 생성된 뒤에만 사용합니다. 등록 단계에서는 단계형 흐름을 사용합니다.
5. 계획값과 실제값을 같은 열에서 덮어쓰지 않고 나란히 비교합니다.
6. 선수 목록은 정상 선수보다 제한·충돌·누락 선수를 먼저 찾을 수 있게 합니다.
7. 완료를 막는 문제와 완료 후 보완 가능한 누락을 분리합니다.
8. 상태를 색상만으로 표시하지 않고 `예정`, `기록 정리`, `연기` 같은 문구를 함께 씁니다.
9. 경기장 모바일에서는 한 손 조작과 임시 저장을 우선하고 복잡한 편집은 숨깁니다.
10. 성과 숫자 카드는 등록·운영 화면의 첫 영역에 두지 않습니다.

## 9. 상세 요구사항

### 9.1 CAL-01 일정 캘린더

#### 기본 구성

- 월 / 주 보기
- 전체 선수단 / 공식 스쿼드 / 운영 그룹 범위
- 일정 유형 필터: 훈련, 경기, 회복, 회의, 휴식
- 일정 상태 필터: 작성 중, 예정, 진행 중, 기록 정리, 완료, 연기, 취소
- 주 행동: `일정 만들기`

#### 일정 카드

- 시작 시각과 예상 시간
- 일정 유형
- 제목과 장소
- 대상 스쿼드·그룹 칩
- 상태
- 확인이 필요한 예외 수

통합 훈련은 스쿼드마다 별도 카드로 만들지 않습니다.

#### 빈 상태

- 일정이 없음: `이 범위에 등록된 일정이 없습니다.` + `일정 만들기`
- 필터 결과 없음: 적용된 필터 + `필터 초기화`

### 9.2 CAL-02 일정 유형 선택

`일정 만들기`를 누르면 먼저 다음 중 하나를 선택합니다.

- 훈련 만들기
- 경기 등록
- 회복·회의·휴식 만들기

훈련에는 `최근 템플릿으로 시작`을 함께 제공합니다. 경기에는 `예정 경기 불러오기`를 후속 연동 기능으로 둡니다.

### 9.3 TRN-01 훈련 등록

#### 단계

```text
1 기본 정보 → 2 대상 → 3 훈련 계획 → 4 담당자·준비 → 5 검토
```

#### 저장 방식

- 모든 단계에서 `작성 중 저장`
- 필수 정보가 갖춰지면 `예정으로 확정`
- 취소 시 저장하지 않은 입력이 있으면 `계속 작성 / 작성 중 저장 / 나가기`

#### 최종 검토

- 예상 대상 계산식과 인원
- 제한·충돌 선수
- 담당자와 미배정 블록
- 전체 시간과 블록 합계
- 시간·장소 충돌

### 9.4 TRN-02 훈련 상세

#### 상단

- `훈련 · 예정` 같은 상태
- 제목, 시간, 장소
- 전체 강도와 대상
- 준비도: 계획 / 참가자 / 담당자 / 데이터
- 주 행동은 상태별로 변경
  - 작성 중: `계속 작성`
  - 예정: `준비 점검`
  - 시작 30분 전: `훈련 시작`
  - 진행 중: `현장 운영 계속`
  - 기록 정리: `기록 확인`
  - 완료: `훈련 복제`

#### 본문

- 개요
- 참가자
- 훈련 계획
- GPS·RPE
- 메모·피드백
- 변경 기록

### 9.5 TRN-03 훈련 참가자

- 공식 스쿼드, 운영 그룹과 개인 추가·제외
- 예상 인원 계산식
- 선수별 주 소속과 참가 방식
- 부상·재활·참가 제한 결과
- 일정 겹침
- 일괄 포함·제외

등록 종료 선수는 검색 결과에서 숨기지 않고, 날짜 기준으로 포함 불가 이유를 확인할 수 있게 합니다. 담당 범위 밖 선수는 검색 결과 자체에 노출하지 않습니다.

### 9.6 TRN-04 훈련 계획

- 훈련 목적과 전체 강도
- 블록 순서 변경
- 블록명, 시간, 강도, 그룹, 담당자, 코칭 포인트
- 계획 총 시간과 일정 예상 시간 비교
- 템플릿 적용·저장

블록을 삭제하면 연결된 실제 실행 기록이 있는지 확인합니다. 진행 이후에는 계획 블록을 삭제하지 않고 `실행 안 함`으로 처리합니다.

### 9.7 TRN-05 훈련 준비 점검

화면을 다음 네 영역으로 구성합니다.

1. 참가 제한과 확인이 필요한 선수
2. 시간·장소·다른 일정 충돌
3. 담당자와 준비물
4. 훈련 블록과 전체 시간

문제가 없으면 `훈련 시작 준비 완료`, 차단 문제는 해결 행동을 함께 제공합니다.

### 9.8 TRN-06 훈련 현장 운영

현장에서는 다음 순서로 사용합니다.

```text
실제 참가자 확인 → 훈련 시작 → 블록 실행 → 빠른 메모 → 훈련 종료
```

- 불참, 지각, 조기 종료, 제한 참여
- 개인 추가와 참가 방식
- 현재 블록과 다음 블록
- 계획 대비 실제 시간
- 선수별 빠른 메모
- 오프라인 저장 상태

상세 GPS 분석과 긴 피드백 작성은 현장 화면에 넣지 않습니다.

### 9.9 TRN-07 훈련 기록 정리

- 계획 대상과 실제 참가 비교
- 계획 블록과 실제 실행 비교
- 실제 총 시간
- GPS·RPE 연결 상태
- 후속 조치와 담당자
- 완료 차단 항목과 나중에 보완할 항목 구분

`훈련 완료` 후 일반 편집은 잠기고 `정정 요청`으로 전환합니다.

### 9.10 TRN-08 훈련 템플릿

- 최근 사용, 팀 공용, 내 템플릿, 구매한 템플릿
- 목적·강도·시간·블록 수 필터
- 미리보기와 새 훈련 적용
- 이름 변경, 복제, 사용 종료

사용 이력이 있는 템플릿은 삭제하지 않고 사용 종료합니다.

세션 마켓에서 구매한 자료는 구매 버전의 복사본으로 저장합니다. 판매자의 이후 수정이 팀 세션에 자동 반영되지 않으며, 실제 선수·GPS·의료 정보는 판매 자료에 포함할 수 없습니다. 상세 거래 정책은 [지도자 세션 마켓·팀 재무 관리 기획서](./COACH_MARKETPLACE_FINANCE_PRD.md)를 따릅니다.

### 9.11 MAT-01 경기 목록

- 시즌과 대회 필터
- 예정 / 완료 / 연기·취소 탭
- 상대, 날짜, 대회, 홈·원정, 상태
- 엔트리·라인업·결과 준비 상태
- 주 행동: `경기 등록`

승률과 시즌 통계는 보조 영역으로 두고 경기 등록·준비보다 먼저 보여주지 않습니다.

### 9.12 MAT-02 경기 등록

#### 단계

```text
1 경기 정보 → 2 대상·담당자 → 3 운영 정보 → 4 검토
```

#### 검토 항목

- 중복 경기 후보
- 시즌 범위
- 다른 경기·훈련과 대상 충돌
- 상대·장소 미정 항목
- 엔트리 마감과 경기 규칙

### 9.13 MAT-03 경기 상세

#### 상단

- 경기 상태
- 상대, 대회·라운드
- 킥오프, 장소, 홈·원정
- 엔트리 / 라인업 / 경기 기록 준비도
- 상태별 주 행동
  - 예정: `엔트리 준비`
  - 엔트리 확정: `라인업 작성`
  - 진행 중: `경기 기록`
  - 결과 확인: `결과 검토`
  - 완료: `경기 기록 보기`

#### 본문

- 개요
- 엔트리
- 라인업
- 경기 기록
- GPS·부하
- 총평·피드백
- 변경 기록

### 9.14 MAT-04 경기 엔트리

- 대상 스쿼드 선수와 허용된 교차 스쿼드 선수
- 등록 상태, 출전 정지, 참가 제한
- 등번호
- 엔트리 최대 인원과 마감 시각
- 선수 추가·제외 사유
- `엔트리 확정`

### 9.15 MAT-05 라인업·역할

- 선발 / 벤치 / 제외
- 포지션과 포메이션
- 주장과 골키퍼
- 드래그 이동과 목록 편집을 함께 제공
- 선발 인원, 엔트리 밖 선수와 역할 누락 확인
- `라인업 확정`

포메이션 보드는 보조 시각화이며 목록이 저장 기준입니다.

### 9.16 MAT-06 경기 기록

- 현재 점수와 경기 시간
- 득점·자책골
- 교체
- 카드
- 부상·조기 종료
- 전술 변경과 내부 메모
- 임시 저장·동기화 상태

1차 버전은 실시간 중계가 아니라 현장·경기 후 빠른 입력을 목표로 합니다.

### 9.17 MAT-07 경기 결과 확인

- 정규·연장·승부차기 점수 분리
- 경기 이벤트와 점수 비교
- 선발·교체·퇴장과 출전 시간 비교
- GPS 연결과 누락
- 감독 총평과 후속 조치
- `경기 완료`

### 9.18 MAT-08 경기 정정

- 정정할 항목
- 현재 값과 새 값
- 정정 사유
- 영향을 받는 선수 기록과 시즌 통계
- 승인 권한
- 정정 후 변경 기록

## 10. 취소·연기 UX

### 훈련 취소

- 취소 사유
- 영향 선수·스태프
- 연결된 참가·메모 존재 여부
- 공개본 변경 대상
- `훈련 취소`

시작 기록이 있으면 취소 대신 중단 또는 기록 정리로 안내합니다.

### 경기 연기

- 기존 킥오프
- 연기 사유
- 새 일시 미정 / 바로 입력
- 기존 엔트리 유지 여부
- 새 경기일 자격 재검사 안내
- `경기 연기`

### 경기 취소

- 취소 사유와 공식 처리 상태
- 엔트리·라인업·공개본 영향
- `경기 취소`

## 11. 모바일 범위

### 제공

- 오늘 훈련·경기 조회
- 실제 참가자 확인
- 불참·지각·제한 참여
- 훈련 블록 진행과 빠른 메모
- 경기 이벤트와 교체
- 종료 후 최소 확인
- 오프라인 임시 저장

### 제공하지 않음

- 복수 스쿼드 대상 규칙 대량 편집
- 훈련 템플릿 관리
- 복잡한 라인업 일괄 편집
- 완료 후 정정
- 시즌 통계 설정

## 12. 문구 기준

- `일정 생성`보다 `훈련 만들기`, `경기 등록`을 사용합니다.
- `출석`보다 `실제 참가자`를 사용합니다.
- `삭제` 대신 상태에 맞게 `작성 중 삭제`, `훈련 취소`, `경기 연기`, `경기 정정`을 사용합니다.
- `저장 완료`와 `경기 완료`를 구분합니다.
- `문제가 발생했습니다` 대신 구체적인 대상과 원인을 씁니다.

## 13. 완료 조건

### 훈련

- [ ] 일정에서 훈련을 만들고 작성 중으로 저장할 수 있다.
- [ ] 복수 스쿼드·그룹·개인을 조합해 예상 대상을 계산할 수 있다.
- [ ] 훈련 블록과 담당자를 구성하고 예정으로 확정할 수 있다.
- [ ] 실제 참가와 제한 참여를 기록할 수 있다.
- [ ] 훈련 후 참가·실행·GPS·RPE·메모를 검토하고 완료할 수 있다.
- [ ] 게시 훈련을 삭제하지 않고 취소·정정할 수 있다.

### 경기

- [ ] 경기 기본 정보를 등록하고 중복 후보를 확인할 수 있다.
- [ ] 엔트리와 라인업을 분리해 확정할 수 있다.
- [ ] 다른 스쿼드 선수를 소속 변경 없이 엔트리에 포함할 수 있다.
- [ ] 득점·교체·카드·부상 이벤트를 기록할 수 있다.
- [ ] 점수·이벤트·출전 기록을 검토하고 완료할 수 있다.
- [ ] 경기 연기·취소·중단과 완료 후 정정을 구분할 수 있다.

### 공통

- [ ] 동시 수정 시 상대 변경과 현재 입력을 비교할 수 있다.
- [ ] 통신 실패와 재시도에서 입력을 잃거나 중복 생성하지 않는다.
- [ ] 모든 주요 변경이 실행자·시각·이전 값과 함께 기록된다.
- [ ] 권한 없는 선수와 스쿼드가 검색 결과에 노출되지 않는다.

## 14. 개발 우선순위

3. 훈련 현장 운영과 기록 정리
4. 경기 등록·엔트리·라인업
5. 경기 이벤트·결과 확인
6. 연기·중단·완료 후 정정
7. 코치 모바일 현장 기록과 오프라인 동기화
